## Docker Environment Configuration

### 1. Build the Earth2Studio Docker Image

Navigate to your Earth2Studio directory and build the container:

```bash
cd /home/younes.abid/git/earth2studio
bash scripts/docker/earth2studio/build.sh
```

**Expected Output:** Successful Docker image build with no errors

### 2. Launch the Container

Start the container with GPU support and proper volume mounts:

```bash
bash scripts/docker/earth2studio/run.sh
```

This script should:
- Mount your Earth2Studio directory into the container
- Enable GPU access
- Set up proper networking
- Configure environment variables

### 3. Verify Container Environment

Once inside the container, run these validation commands:



## Performance Baseline

### 1. GPU Memory Check

```bash
# Check available GPU memory
python -c "
import torch
if torch.cuda.is_available():
    gpu_count = torch.cuda.device_count()
    for i in range(gpu_count):
        props = torch.cuda.get_device_properties(i)
        memory_gb = props.total_memory / 1e9
        print(f'GPU {i}: {props.name}, {memory_gb:.1f}GB')
        
        # Check current memory usage
        torch.cuda.set_device(i)
        allocated = torch.cuda.memory_allocated() / 1e9
        cached = torch.cuda.memory_reserved() / 1e9
        print(f'  Memory - Allocated: {allocated:.2f}GB, Cached: {cached:.2f}GB')
else:
    print('❌ No CUDA GPUs available')
"
```

## Troubleshooting

### Container Build Fails
```bash
# Clean Docker cache and rebuild
docker system prune -f
bash scripts/build_docker.sh --no-cache
```

### GPU Not Accessible in Container
```bash
# Check if nvidia-docker2 is installed
docker info | grep nvidia

# Test with explicit runtime
docker run --rm --gpus all --runtime=nvidia nvidia/cuda:11.8-base-ubuntu20.04 nvidia-smi
```

### PhysicsNeMo Import Errors
```bash
# Check if PhysicsNeMo is properly installed in container
pip list | grep physicsnemo
pip install --upgrade physicsnemo
```
