# 1.1 Prerequisites Check

> **⏱️ Time:** 30-45 minutes

## System Requirements

### Hardware
- **GPU:** NVIDIA GPU with CUDA capability (required for CorrDiff inference)
- **RAM:** Minimum 16GB, recommended 32GB+
- **Storage:** At least 50GB free space for models and data

### Software
- **OS:** Linux (confirmed working on your current setup)
- **Docker:** Version 20.10+ with GPU support
- **NVIDIA Container Toolkit:** For GPU access in containers

## Quick Validation Commands

Run these commands to verify your setup:

### 1. Check GPU Availability
```bash
nvidia-smi
```
**Expected:** Should show your GPU(s) and driver version

### 2. Verify Docker Installation
```bash
docker --version
docker run --rm hello-world
```
**Expected:** Docker version info and successful container run

### 3. Test GPU in Docker
```bash
docker run --rm --gpus all nvidia/cuda:11.8-base-ubuntu20.04 nvidia-smi
```
**Expected:** Same GPU info as step 1

### 4. Verify Checkpoint Access
```bash
ls -la /home/younes.abid/git/physicsnemo/outputs/checkpoints/
```
**Expected:** Should show your trained model files:
- `regression_model.mdlus`
- `diffusion_model.pt`

### 5. Check Earth2Studio Directory
```bash
ls -la /home/younes.abid/git/earth2studio/
```
**Expected:** Should show the complete Earth2Studio structure

## Troubleshooting Common Issues

### GPU Not Found
```bash
# Check NVIDIA driver
nvidia-smi

# Install NVIDIA Container Toolkit if missing
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list

sudo apt-get update && sudo apt-get install -y nvidia-docker2
sudo systemctl restart docker
```

### Docker Permission Issues
```bash
# Add user to docker group
sudo usermod -aG docker $USER
# Log out and back in, or run:
newgrp docker
```

### Missing Checkpoint Files
If your checkpoints are missing or in a different location:
```bash
# Find your actual checkpoint files
find /home/younes.abid/git/physicsnemo -name "*.mdlus" -o -name "*.pt" 2>/dev/null
```
